# Infrastructure and free-tier register

Founder cost policy (2026-11-28): no paid software or services beyond the existing **Vercel**,
**ChatGPT** and **Claude** subscriptions. This register lists every outside service the
platform depends on. Limits were read from each provider's published pricing and documentation
on 2026-11-28 and change over time: **re-check before relying on a number**. No account was
created, no plan was changed and nothing was bought while preparing this register.

Classification: **free** (free plan, no card), **included** (inside a subscription the founder
already pays), **usage-based** (charged per use beyond an allowance), **one-time**,
**recurring**, **optional** (not needed for the pilot).

Expected pilot usage assumes the 14-day pilot with 2-3 cafés in Abu Dhabi: about 50 orders a
day, under 300 customers, under 30 staff and admin users, under 100 MB of documents.

## Not used, on purpose

| Service                                | Why not                                                                                                              |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Redis / BullMQ hosting                 | Replaced by the PostgreSQL outbox and rate-limit table                                                               |
| Twilio or any SMS provider             | Email sign-in only (founder decision)                                                                                |
| AWS, Azure, Oracle Cloud               | Excluded by the founder                                                                                              |
| Paid malware scanning, ClamAV hosting  | No free option allows commercial use; ClamAV does not fit a Vercel function. Production uploads stay blocked instead |
| VirusTotal public API                  | Terms forbid commercial use                                                                                          |
| Paid monitoring (Sentry paid, Datadog) | Vercel and Supabase built-in logs during the pilot (short retention, see docs/27)                                    |
| Vercel Password Protection add-on      | Paid; Vercel Authentication (free) protects staging                                                                  |

## Watch list (free limits most likely to be reached first)

1. **Supabase project pause after 7 idle days**: staging goes offline until someone resumes it
   in the dashboard. We do not send artificial traffic to prevent this (founder instruction,
   cycle 4); resume it by hand after a quiet week (docs/31).
2. **No Supabase backups on Free**: daily encrypted export from a private GitHub repository, kept 7 days (docs/30). GitHub Free private repositories include 2,000 Actions minutes and 500 MB artifact storage a month; with no payment method on file, usage is blocked rather than billed. The older manual drill (`apps/api/scripts/backup-restore-check.sh`)
   still works for a one-off copy to an encrypted device; keep dumps encrypted and off GitHub.
3. **Resend 100 emails a day**: enough for the pilot; a public launch would exceed it.
4. **Supabase 500 MB database**: years of pilot-scale orders fit; audit and outbox rows grow
   fastest.
5. **Vercel Hobby**: if the existing plan is Hobby, per-minute cron is unavailable and
   commercial use is not allowed, so the plan must be confirmed before staging.
